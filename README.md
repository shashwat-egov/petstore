# Petstore Spring Boot Application

This project is a minimal implementation of the Swagger Petstore using Spring Boot 3.2.2 and Java 17.

## Requirements
- Java 17
- Maven

## Running locally

```
mvn spring-boot:run
```

The application uses an in-memory H2 database. The H2 console is available at `/h2-console`.

## Available Endpoints
The API roughly follows the operations described in `petstore.yaml`.
